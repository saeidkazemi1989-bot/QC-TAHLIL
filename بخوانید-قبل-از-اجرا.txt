اول فایل زیپ را Extract کنید!
────────────────────────────────
روی فایل زیپ راست‌کلیک کنید و Extract All را بزنید
(یک پوشه معمولی بسازید، مثلاً روی دسکتاپ).
وقتی داخل زیپ هستید و فایل‌ها را باز می‌کنید،
آدرس فایل‌ها چیزی شبیه ...\Temp\....zip.73d\... است
و در آن حالت هیچ برنامه‌ای درست کار نمی‌کند.


راه اول: دیدن سریع، بدون هیچ نصبی (توصیه برای شروع)
────────────────────────────────
روی فایل  QC-Dashboard.html  دبل‌کلیک کنید.

   · یک فایل مستقل است: نه اینترنت می‌خواهد، نه نصب، نه سرور.
   · داده‌های فعلی درون خودش ذخیره شده‌اند.
   · صفحه اول نقش را انتخاب کنید و نمودارها را ببینید.
   · در این نسخه فقط «انتخاب منبع عیب» (حین تولید / بازرسی) فعال است
     و امکان بارگذاری داده جدید ندارد.
   · برای فیلترهای کامل و به‌روزرسانی داده، راه دوم را استفاده کنید.


راه دوم: نسخه کامل (فیلترها، به‌روزرسانی داده، مدیریت کاربران)
────────────────────────────────
۱) اگر Node.js نصب ندارید، یک‌بار آن را نصب کنید:
       https://nodejs.org
   نسخه‌ی ۲۲ LTS یا بالاتر (نصب با Next > Next).

۲) روی فایل  start.bat  دبل‌کلیک کنید.

   · بار اول فقط نصب وابستگی‌ها چند دقیقه طول می‌کشد؛ صبر کنید.
   · مرورگر خودبه‌خود روی  http://localhost:3000  باز می‌شود.
   · تا وقتی آن پنجره‌ی سیاه باز است، برنامه در دسترس است.
     برای بستن برنامه همان پنجره را ببندید.

   اگر ترجیح می‌دهید دستی اجرا کنید، در پوشه پروژه بنویسید:
       npm install        (فقط بار اول)
       npm start


نکته مهم
────────────────────────────────
فایل public\index.html را با دبل‌کلیک باز نکنید؛
این برنامه یک سرور دارد و در حالت فایل (file://)
فقط پیام «در حال بارگذاری سامانه» را می‌بینید.
برای دیدن سریع، همان QC-Dashboard.html را باز کنید.


ورود و سطح دسترسی
────────────────────────────────
   مدیر ارشد        → نمای کلی، داشبورد مدیریتی، تولید، راهنما
   کارشناس کیفیت    → تحلیل حین تولید، اسناد بازرسی، PFMEA، رکوردها
   مدیر سیستم       → همه صفحه‌ها + بارگذاری داده و مدیریت کاربران


به‌روزرسانی داده‌ها (نسخه کامل)
────────────────────────────────
۱) چهار فایل خام خروجیِ راهکاران را در پوشه‌ی  data\raw  بگذارید.

۲) دستور زیر را بزنید (یا فایل refresh.bat را اجرا کنید):
       npm run refresh
   این دستور ابتدا گزارش‌ها را با ابزار تبدیل شما (qc.py) تمیز
   می‌کند و بعد وارد داشبورد می‌کند.

   اگر خودتان ابزار تبدیل را با run_windows.bat اجرا کرده‌اید،
   خروجی را در پوشه‌ی  data\clean  بگذارید و فقط بنویسید:
       npm run import

۳) برای به‌روزرسانی نسخه آفلاین:
       npm run export

نکته: فایل‌های داخل data\raw فقط ورودیِ ابزار تبدیل هستند و
مستقیماً وارد داشبورد نمی‌شوند؛ داشبورد گزارش‌های تمیز را
از پوشه‌ی data\clean می‌خواند.


توضیح کامل‌تر در README.md
در صورت بروز مشکل، متن پنجره‌ی سیاه را بفرستید.
